# ADR 0003: Guest-first student experience

Status: superseded by 0005

Do not create student identity in the MVP. Browsing and contribution are anonymous, saved IDs remain local to the current device, and submissions are online-only. Only staff have CMS accounts. This minimizes friction and personal-data risk while validating the directory’s usefulness.

0005 keeps guest-first as the default for everyone — nothing here changes for a student who never signs in — but permits an optional account for saved-opportunity sync, which this ADR originally ruled out entirely.
