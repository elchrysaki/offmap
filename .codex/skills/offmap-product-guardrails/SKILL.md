# OffMap product guardrails

1. Read `AGENTS.md`, `docs/PRODUCT.md`, `docs/BRAND.md`, and `references/review-checklist.md`.
2. Identify the student job and platform surfaces affected before changing files.
3. Keep the MVP guest-first and centered on discover, save, and contribute.
4. Use the approved paper-collage tokens and selectable responsive text; never ship the old Enchanted Map, quest, or unicorn language.
5. Verify native Discover/Saved/Add navigation and web Home/Opportunities/Saved/Submit/About behavior where relevant.
6. Check complete loading, empty, error, offline, focus, keyboard, screen-reader, dynamic-type, reduced-motion, contrast, and touch-target states.
7. Run focused automated checks. State simulator, physical-device, distribution, store, and production gates separately.
